# Nova для Civilization V

Nova — модпак с новыми бонусами цивилизаций, изменениями баланса и турнирными картами для сетевых партий.

1. Откройте [сайт Nova](https://coddysmon.github.io/TournamentModPack/#download) и нажмите «Скачать лаунчер».
2. Распакуйте архив, запустите `Civ5Launcher.exe` и следуйте подсказкам лаунчера.

- [Что меняет Nova](https://coddysmon.github.io/TournamentModPack/changes.html)
- [Установка, помощь и Discord](https://coddysmon.github.io/TournamentModPack/faq.html)

Здесь находятся сайт Nova и файлы для раздачи обновлений. Полный исходный код мода здесь не опубликован.
