# Nova для Civilization V

**Nova — полноценный мод для Civilization V: Brave New World с собственным лаунчером и сайтом со статистикой сетевых партий.** Мод добавляет бонусы цивилизаций, ресурсы и турнирные карты, меняет баланс и игровые механики. Лаунчер устанавливает и обновляет мод, а на сайте можно смотреть статистику и повторы партий.

## Скачать и начать играть

1. Откройте [страницу скачивания](https://coddysmon.github.io/TournamentModPack/#download) и нажмите «Скачать лаунчер».
2. Распакуйте архив, запустите `Civ5Launcher.exe` и следуйте подсказкам.

[Гайд новичка](https://coddysmon.github.io/TournamentModPack/guide/gaid-418e9820.html) · [Установка, помощь и Discord](https://coddysmon.github.io/TournamentModPack/faq.html)
