# TournamentModPack

Модпак Civilization V и лаунчер к нему.

Здесь лежит только лёгкое: **`manifest.json`** — список файлов модпака с их размерами и
SHA-256, и `PATCH_VERSION.txt` — текущая версия. Самих файлов модпака в репозитории нет
и не будет: 236 МБ полезной нагрузки в истории git сделали бы клонирование мучением.

**Файлы раздаются ассетами релиза с тегом `cas`.** Имя ассета — это SHA-256 файла,
поэтому:

* выложенный файл годится для всех будущих версий, и новая версия доливает в хранилище
  только изменившееся (типичная суточная правка — единицы мегабайт вместо 236);
* один и тот же файл, нужный в нескольких местах установки, скачивается один раз;
* содержимое проверяется хешем на стороне клиента, подменить его по дороге нельзя.

Тег `cas` — служебный и общий для всех версий; версии различаются манифестом, а не
хранилищем. Качать оттуда руками нечего.

## Как этим пользуется лаунчер

В настройках клиента задан один адрес — этого манифеста. Где лежат файлы, клиент узнаёт
из самого манифеста (блок `content`), поэтому хранилище можно переносить и зеркалить,
не обновляя клиент у игроков.

```
manifest.json
  content.baseUrl  https://github.com/Coddysmon/TournamentModPack/releases/download/cas/
  content.layout   Flat            имя файла в хранилище = его SHA-256
  components[]     mod / maps-game / maps-user — модпак едет в три разных каталога
```

Проверить, что раздача выложена целиком:

```
tmtool verify-remote --url https://raw.githubusercontent.com/Coddysmon/TournamentModPack/main/manifest.json
```
