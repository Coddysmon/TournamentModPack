Help

Installation, updates, multiplayer and the usual breakages. If the answer is not here, ask on Discord — the link is at the bottom of the page.

Installation

  1. Check that you have the game itself. You need Civilization V with the Brave New World expansion, bought on Steam. Without BNW the mod will not work.
  2. Download the launcher — the button on the home page, …. If GitHub won't download (some providers block it), there is a backup address: . It is served over plain http, and the browser may refuse to download from the link — in that case paste the address into a new tab.
  3. Unpack the whole archive into any folder and run Civ5Launcher.exe. Do not run the program straight from inside the archive: the libraries it needs sit next to it, and without them it will not start.
  4. Nothing else has to be installed — no .NET, no Visual C++ runtimes. Administrator rights are not needed either.
  5. The launcher installs itself into %LOCALAPPDATA%\Programs\Nova Launcher\, creates shortcuts and shows up in “Apps & features”. Then press “Обновить” (Update) — it will find the game and install the mod.
  6. The “Играть” (Play) button starts the game through Steam. The mod loads by itself: you do not have to enable it in the mods menu, and you could not if you wanted to — it is installed as an expansion, not as a Workshop modification.

Updates

  • The launcher checks every file by hash, not by date, and downloads only what actually changed. A routine daily update is a few megabytes, not the whole mod pack.
  • An interrupted update does not break the mod. Everything is downloaded first and only then replaced; if it breaks off halfway, the next start finishes the job and says plainly that the previous install was incomplete.
  • If the mod folder was wiped from outside (by a mod-pack switcher, for instance), just start the launcher: it sees what is missing and restores it.
  • After an update the launcher clears the game's database cache — four files. It never touches saves or match history; those files are on a separate “do not touch” list.

Multiplayer

  • Everyone in the match must be on the same version. The mod ships its own build of the game engine, and a mismatch causes a desync. In the lobby list the launcher shows the host's build, so you see the mismatch before joining. If versions have diverged, the host gets a message along the lines of “Version mismatch with player”.
  • Joining takes time. With the game closed, Steam has to launch it first, and the invite only fires at the main menu — that is 40 to 90 seconds. The launcher shows this waiting time; don't press the button again.
  • Friends' lobbies do not show up in the public Steam list. The launcher looks at both sources, so a friend's lobby is visible even when the public list does not have it.
  • Turn your VPN off while playing. This is not superstition: we measured it — with a tunnel up, the connection drops roughly every 45 seconds, direct Steam connections between players time out, and unit orders take a second or two to go through. Tunnel off, delays gone completely.

Subscription and appearance

  • The subscription only changes the way things look and unlocks nothing in the game: no unit, no building, no bonus. It has no effect on balance or rules.
  • Free for everyone — the mod pack itself and multiplayer, the launcher themes and the profile avatar.
  • From “Bronze” — the choice of cursor (every cursor in the set, sizes 32, 48 and 64), the colour and font of your name, the tier emblem next to your name in the launcher, a metal rim around the unit icon, and a custom background image (the game's main menu and the launcher window).
  • From “Silver” you also get a badge next to your name in game, a profile of your own in the launcher (banner, colour and glow of the avatar frame, a motto) and a place in beta tests.
  • From “Gold” — name lettering styles (outline, shadow, glow), unit skins, voice commands in game and priority support.
  • The full table of tiers and prices is on the subscription page.
  • You buy inside the launcher, section “Подписки” (Subscriptions). There is no sign-up: your code is the account.
  • Moving to another computer — enter the same code there, in the transfer field.
  • The cursor is changed in “Настройки → Курсоры” (Settings → Cursors); without a subscription you get the game's standard cursor. While the game is running the cursor file is locked — change it before you start.
  • Unit skins are switched in the launcher and come with the “Gold” tier. A skin does not change a unit's stats, and everyone in the match sees it.

What to do when it doesn't work

Windows complains about the launcher: SmartScreen and antivirus

This is expected, and it is not a virus. We do not sign our files with a paid developer certificate — it costs money and is hard for a private person in Russia to obtain. To Windows that means “a program with no name and no reputation”, so it warns you. We give the antivirus a second reason ourselves: the launcher puts its own steam_api.dll into the game folder (that is how our relay works when Steam cannot connect players directly), and Steam emulators look exactly the same from outside — the antivirus sees the shape, not the intent.

The blue SmartScreen window

Its title is “Windows protected your PC”.

  1. In the blue window click “More info”.
  2. A “Run anyway” button appears — that is the one that starts the launcher.
  3. If the warning is about the archive itself: right-click the .zip → “Properties” → the “Unblock” checkbox at the bottom → “Apply”, and only then unpack it.

An exclusion in Windows Defender

  1. Start → type “Windows Security” and open the app.
  2. “Virus & threat protection” → under “Virus & threat protection settings” click “Manage settings”.
  3. Scroll down to “Exclusions” → “Add or remove exclusions”.
  4. “Add an exclusion” → “Folder” → point it at %LOCALAPPDATA%\Programs\Nova Launcher\ (you can paste the path straight into the address bar of the picker).
  5. If you play with our relay switched on, add the Civilization V install folder as a second exclusion.

Other antivirus products (Kaspersky, Dr.Web, Avast) name the menus differently, but the idea is the same: add these folders to the exclusions. If the antivirus has already deleted the file, restore it from quarantine and then add the exclusion; downloading it again into the same folder is pointless — it will be deleted again.

Checking that the file is ours

Compare the checksum of the archive you downloaded. It is published with every release and changes with each version:

File…, …
SHA-256…

This is the very same value that sits in manifest.json under client.sha256 — the file is distributed together with the mod, and the launcher itself reads it when updating. To check on your side: right-click the folder with the archive → “Open in Terminal” (or PowerShell) and run

Get-FileHash .\nova-client-version.zip -Algorithm SHA256

The Hash line in the answer must match the table above, ignoring case. If it matches, the file is exactly the one we published and nobody swapped it on the way.

The launcher “hangs” and Task Manager can't kill it

We have only ever seen this caused by an antivirus: a fresh unsigned .exe in a new folder is a favourite target for heuristics. The same folder exclusion for %LOCALAPPDATA%\Programs\Nova Launcher\ fixes it.

“Update server unavailable… an attempt was made to access a socket in a way forbidden by its access permissions”

This is not a network problem and not a broken launcher, but a VPN filter with per-application split tunnelling: the launcher is not on its allowed list, so the program is forbidden to open connections. One-minute check: if github.com opens in the browser while the launcher complains, it is the filter.

What to do: turn split tunnelling off, or add the launcher to the VPN's exclusion list. One more symptom: a path containing non-Latin letters in the user name is sometimes stored mangled by such filters and then not recognised — in that case installing the launcher into a folder without Cyrillic, for example C:\Nova, helps.

The “Play” button does nothing

Steam will not start the game while it believes the game is already running. The launcher waits for it to be released and tells you if the game never appears. If you see that message, close the launcher completely and start the game from Steam; after that you can open the launcher again.

The game crashes on start, or the mod is not there

  1. Open the launcher and make sure the installation is complete (not “не завершена”).
  2. Clear the database cache in “Настройки → Игра” (Settings → Game).
  3. Collect the logs: “Настройки → Логи игры” (Settings → Game logs). The launcher will enable logging in the game, gather the files, hide the known noise and show the first real error.
  4. Attach the archive to your message on Discord.
About the logs, honestly. The archive is built on your disk and never leaves it by itself. Before collecting, the launcher shows a consent screen and lists what personal data it found in the files (your Windows user name, your Steam name, your profile path) and how many times. A “strip personal data” checkbox is there too. Whether to send it is your call.

Kicked out of the match right after the lobby, with a defeat screen

This is not a network error and not a version mismatch: the logs are empty in that case, and the host gets no mismatch message. The cause is investigated separately — write on Discord with your name and the time of the match.

The mod disappeared after switching mod packs

Third-party mod-pack switchers wipe whole folders — that is how we lost the maps twice and the interface files once. The cure is to start the launcher: it compares the installation against the reference and brings back what was erased.
